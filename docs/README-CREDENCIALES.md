## 🧭 ¿Qué puede probar cada usuario?

| Rol | Funcionalidades principales |
| :-- | :-- |
| **CLIENTE** | Explorar tiendas, consultar productos, agregar al carrito, crear pedidos y revisar su estado. |
| **EMPRENDEDOR** | Gestionar tiendas y productos, actualizar existencias y preparar pedidos. |
| **REPARTIDOR** | Ver sus entregas, consultar destinos autorizados, iniciar recorridos y completarlos. |
| **ADMIN** | Acceder al panel MVC, revisar entregas, asignar repartidores disponibles y cancelar asignaciones permitidas. |
